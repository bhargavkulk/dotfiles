#+title: My dotfiles
#+author: Bhargav Kulkarni

Setting up:

#+begin_src bash
git init --bare ~/.conf
alias conf='/usr/bin/git --git-dir="$HOME/.conf/" --work-tree="$HOME"'
conf config status.showUntrackedFiles no
#+end_src

Replicating on new machine:

#+begin_src bash
git clone --bare <git-repo-url> $HOME/.conf
alias conf='/usr/bin/git --git-dir="$HOME/.conf/" --work-tree="$HOME"'
conf checkout
conf config --local status.showUntrackedFiles no
#+end_src

Remember to always run the =conf= command from =$HOME=.
